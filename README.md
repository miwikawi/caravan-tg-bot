# Караван Coca-Cola: мини-апп с двумя концептами + бот

Один сервис на Railway: отдаёт мини-апп (папка public) и запускает бота.

## Запуск на Railway (Mac, Терминал)

1. Распакуйте архив и откройте папку в Терминале:
   cd ~/Downloads/caravan-miniapp
2. Создайте проект и загрузите код:
   railway init        (имя: caravan-miniapp)
   railway up
3. Включите публичную ссылку:
   railway domain
4. Добавьте токен бота (Railway → проект → Variables):
   BOT_TOKEN = токен из BotFather
   После сохранения Railway перезапустит сервис сам.

Проверка: откройте бота, нажмите «Старт». Бот пришлёт фото трака и две кнопки:
«Концепт 1 · Плитки-коробки» и «Концепт 2 · Чистый лендинг». Кнопка меню «Караван» открывает экран выбора концепта.

## Как это устроено
- server.js — веб-сервер для public/ и бот (long polling, без вебхука, зависимостей нет).
- При старте бот сам ставит кнопку меню, команду /start и описание.
- Ссылка на мини-апп берётся из RAILWAY_PUBLIC_DOMAIN (Railway задаёт её после «railway domain»).
  Если домен свой, задайте переменную WEBAPP_URL.
- Мини-апп работает и в обычном браузере по той же ссылке: ?c=tiles или ?c=land открывают концепт сразу.
